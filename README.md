# Cendon — เว็บไซต์แนะนำการใช้งาน

เว็บไซต์สำหรับผู้ใช้ทั่วไป แยกออกจากตัวแอปโดยสิ้นเชิง
ตรานำหน้าใช้ **Phasmion** ส่วนชื่อสินค้าที่พูดถึงทั้งเว็บคือ **Cendon**

เนื้อหาทั้งหมดเป็นเรื่องที่ผู้ใช้ควรรู้เท่านั้น
ไม่มีรายละเอียดฝั่งหลังบ้าน สถาปัตยกรรมระบบ หรือขั้นตอนของทีมงาน

---

## โครงสร้าง

```
cendon-web/
├── build.py            ประกอบหน้าเว็บจากชิ้นส่วน — รันไฟล์นี้ไฟล์เดียว
├── parts/
│   ├── head.html       <head> ที่ใช้ร่วมกันทุกหน้า
│   ├── nav.html        แถบเมนูบน
│   ├── foot.html       ท้ายเว็บ
│   └── art.py          ภาพประกอบทั้งหมด เขียนเป็น SVG ล้วน
├── pages/              เนื้อหาของแต่ละหน้า (แก้ที่นี่)
│   ├── index.html      หน้าแรก
│   ├── features.html   ความสามารถทั้งหมด
│   ├── guide.html      คู่มือใช้งาน 13 หัวข้อ
│   ├── about.html      ความเป็นมา
│   ├── help.html       ศูนย์ช่วยเหลือ
│   ├── terms.html      เงื่อนไขการให้บริการ
│   └── privacy.html    นโยบายความเป็นส่วนตัว
├── assets/
│   ├── site.css        ระบบดีไซน์ทั้งหมด
│   ├── site.js         สลับภาษา เมนู เผยตอนเลื่อน สารบัญ
│   └── phasmion*.svg   ตราสัญลักษณ์
├── fonts/              Spire09 (ใช้กับภาษาอังกฤษ)
└── *.html              ← ไฟล์ที่ build.py สร้าง อย่าแก้ตรงนี้
```

## วิธีแก้และ build

```bash
python3 build.py        # อ่าน pages/ + parts/ แล้วเขียน .html ที่ราก
```

แก้เนื้อหาที่ `pages/` เสมอ ไฟล์ `.html` ที่รากถูกเขียนทับทุกครั้งที่ build

**ทำไมต้องมีขั้นตอน build:** หัวเว็บกับท้ายเว็บเหมือนกันหมดทุกหน้า
ถ้าก็อปวางไว้เจ็ดที่ พอแก้ลิงก์เดียวต้องไล่แก้เจ็ดรอบแล้วลืมสักที่เสมอ

## สองภาษา

ทุกข้อความมี `data-th` และ `data-en` คู่กัน `site.js` สลับให้ตอนกดปุ่มภาษา
และจำไว้ใน `localStorage` ครั้งแรกเดาจากภาษาเบราว์เซอร์

```html
<h2 data-th="ข้อความไทย" data-en="English text">ข้อความไทย</h2>
```

ถ้าข้อความมีแท็กอยู่ข้างใน ให้ใช้ `data-th-html` / `data-en-html` แทน

## ตั้งค่าที่อยู่ของแอป

แก้ `APP_URL` บรรทัดบน ๆ ของ `build.py` ที่เดียว แล้ว build ใหม่

## ภาพประกอบ

อยู่ใน `parts/art.py` ทั้งหมด เป็น SVG ที่เขียนด้วยโค้ด ไม่มีไฟล์รูป
เรียกใช้ในหน้าเพจด้วย `{{ART:ชื่อ}}` เช่น `{{ART:parking}}`

สีในภาพอ้างตัวแปร CSS จึงเปลี่ยนธีมได้จากที่เดียว
คลาสที่ใช้ควบคุมการเคลื่อนไหว:

| คลาส | ผลที่ได้ |
|---|---|
| `rv` | เผยขึ้นมาตอนเลื่อนถึง (มี `rv-d1` ถึง `rv-d4` หน่วงเวลา) |
| `pop` | ชิ้นส่วนเด้งขึ้น (มี `pop-d1` ถึง `pop-d4`) |
| `dash` | เส้นวาดทีละนิด — `site.js` วัดความยาวจริงให้เอง |
| `grow` | แถบยืดจากซ้าย |

การเคลื่อนไหวทั้งหมดใช้ `transform` กับ `opacity` เท่านั้น
และหยุดทำงานทันทีถ้าเครื่องตั้ง `prefers-reduced-motion`

## เอาขึ้นจริง

เป็นไฟล์นิ่งล้วน ไม่ต้องมีเซิร์ฟเวอร์ อัปโหลดทั้งโฟลเดอร์ขึ้นที่ไหนก็ได้
ถ้าใช้บริการที่ build ให้อัตโนมัติ ตั้งคำสั่ง build เป็น `python3 build.py`
และ output directory เป็นรากของโปรเจกต์

## ที่ยังไม่ได้ทำ

- ยังไม่มีหน้า 404
- ยังไม่มี `sitemap.xml` และ `robots.txt` (ใส่ตอนรู้โดเมนจริงแล้วดีกว่า)
- รูป Open Graph สำหรับแชร์ลิงก์ยังไม่ได้ทำ ตอนนี้ใช้แค่ข้อความ
